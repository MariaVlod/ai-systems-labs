# Картки з нотаток

Вебзастосунок, який перетворює нотатки з пари на картки «питання — відповідь» для повторення.
Працює з **локальною** моделлю через OpenAI-сумісний API (Ollama), без хмарних сервісів.
Відповідь приходить стрімінгом; результат — клікабельні картки й експорт у `.tsv` для Anki.

## Що встановити
1. [Ollama](https://ollama.com/download) для Windows.
2. Python 3.10+ (лише щоб віддати статичні файли; бібліотеки не потрібні).

## Яку модель завантажити
```
ollama pull qwen3:4b-instruct-2507-q4_K_M
```
(≈2,5 ГБ). Якщо такого тега немає, візьміть `qwen3:4b-instruct`; для слабшого комп'ютера — `qwen3:1.7b` і тоді увімкніть в застосунку «Вимкнути міркування».

## Запуск
```
ollama serve                                   # якщо Ollama ще не запущено (зазвичай працює у треї)
cd lab4/app
python -m http.server 8000 --bind 127.0.0.1
```
Відкрийте <http://localhost:8000/>. Не відкривайте `index.html` з диска: браузер заблокує запити (CORS).

## Параметри генерації
| Параметр | Значення | Чому |
|---|---|---|
| temperature | 0,3 | потрібен стабільний валідний JSON і точні факти з нотаток, а не творчість |
| max_tokens | 1500 | 10 карток по ~60 токенів ≈ 600–800 токенів, решта — запас; ліміт захищає від зациклення |
| контекст | 4096 (за замовчуванням Ollama) | нотатки обмежені 6000 символами ≈ 2–3 тис. токенів, разом із промптом і відповіддю влазить |
| response_format | json_object | змушує модель повертати JSON |

## Файли
- `index.html` — інтерфейс; `app.js` — запит до моделі, розбір JSON, помилки; `style.css`.
- `test_app.mjs` — перевірка розбору відповіді та обробки помилок (`node test_app.mjs`, потрібен Node 20+).
- `demo/` — відео й скриншоти роботи.
